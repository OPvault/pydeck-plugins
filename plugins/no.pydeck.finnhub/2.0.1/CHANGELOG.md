## 2.0.1 — 2026-10-04

- Now requires PyDeck 2.0.0, which has the shared settings this version follows (Settings → Plugin settings → Shared by all plugins).
- The change line takes the shared status colors: a rise in the good color, a fall in the critical one. A market where red means up is now one swap in the shared settings instead of a code change.
- Prices and percentages follow the shared decimal separator (`1 234,50`, `+1,25%`).
