## 0.1.1 — 2026-10-04

- Now requires PyDeck 2.0.0, which has the shared settings this version follows (Settings → Plugin settings → Shared by all plugins).
- **Status colors** is now one choice: **Use global** (the new default) takes the shared good / warning / critical colors, **Custom** shows three color pickers in a row instead of three hex text fields. A key whose colors were changed before this version stays on Custom with them.
- The thresholds are labeled Warning from / Critical from, since the colors are no longer always amber and red.
- Spelling is American English throughout.
