## 2.0.8 — 2026-10-04

- Now requires PyDeck 2.0.0, which has the shared settings this version follows (Settings → Plugin settings → Shared by all plugins).
- A temperature sensor in °C, °F or K is shown in the shared temperature unit, keeping the decimals Home Assistant sent — for a deck in another unit than the Home Assistant install.
- Numeric sensor values follow the shared decimal separator (`21,5 °C`).
- Spelling is American English throughout.
