## 3.0.2 — 2026-10-04

- Now requires PyDeck 2.0.0, which has the shared settings this version follows (Settings → Plugin settings → Shared by all plugins).
- Hour format and Date format have a new default, **Use global**: the clock follows the shared 12/24-hour and date settings, so every clock on the deck changes together. A clock set to a format keeps it, and the clock-only styles (Month day, Month day year) are still there to pick.
- Spelling is American English throughout.
