## 1.0.9 — 2026-10-04

### Changed

- Press Key and Type Text faces take up to three lines of text. Add or remove lines in the
  button editor; a new button starts with one line ("Key" / "Type").

### Fixed

- Type Text showed a profane second line by default. It is gone.
- Clearing a line left the face showing the template's filler text instead of nothing. The
  templates no longer carry filler, so a blank line now renders blank.
